# P3 Fast NCC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the two-pass full-resolution NCC refine stage with a single fused `wide::f32x8` pass that computes all five NCC sums (Σx, Σx², Σy, Σy², Σxy) at once, while preserving matcher outcomes and benchmark-reporting the speedup.

**Architecture:** The template refine path passes `&PreparedFrame` into NCC scoring. Each offset runs one fused SIMD pass over the clipped overlap rect, accumulating the four normalization sums alongside the cross term — no separate integral image. The scorer is split into `clipped_ncc_rects` (overlap clipping), `fused_sums_wide` (the single SIMD pass), and `ncc_from_sums` (the NCC formula + reject threshold), so the math is unit-testable without building frames. The legacy two-pass NCC stays available only in tests as the equivalence oracle.

**Tech Stack:** Rust (workspace `rust-version` raised only if `wide` requires it), `rollshot-core`, `wide 1.4.0` (no feature gate — `wide` is a portable layer with an automatic software fallback), `rayon`, existing `StitchMetrics`, existing `stitch_sequences` benchmark harness.

---

## Design decisions (now reflected in the design spec)

These three choices were ratified during plan review and the live design spec
`docs/superpowers/specs/2026-05-27-p3-fast-ncc-design.md` has been updated to match
— plan and spec agree. (The older roadmap note
`docs/stitching-rollshot-optimizations-2.md` §5 still describes the original
integral idea and is intentionally left unchanged.)

1. **No integral image; one fused pass.** The cross term `Σxy` already scans every
   pixel of the rect, so the four normalization sums are accumulated in that same
   pass for free. A whole-frame f64 integral would add ~168 MB resident on a retina
   pair (prev+curr, two f64 tables each) and an extra build pass for **no**
   per-offset asymptotic win. The fused single pass is the same O(area) per offset
   with zero extra memory.
2. **`wide`-only, no scalar baseline and no feature flag.** `wide::f32x8` is
   pure-Rust and falls back to a software implementation on targets without hardware
   SIMD, so the portability intent ("scalar still works without SIMD") is satisfied
   without a hand-written scalar twin (which would be duplicate code to keep in
   sync).
3. **Reject threshold `≤ 1.0`, not `≤ 1e-9`.** The existing production
   `ncc_score_shifted` rejects a window when its sum-of-squared-deviations is `≤ 1.0`
   (matcher.rs). `Σx² − (Σx)²/n` is exactly that same quantity. Using `1e-9` would
   make near-flat / low-texture windows that legacy rejected start producing a
   (possibly spurious) correlation — a silent matcher-outcome change. We keep
   `≤ 1.0` to preserve outcomes, and add a low-variance equivalence test to lock it
   in.

```rust
#[cfg(test)]
fn legacy_ncc_score_shifted(
    prev_gray: &[f32],
    curr_gray: &[f32],
    width: u32,
    height: u32,
    region: Region,
    dx: i32,
    dy: i32,
) -> f32 {
    let overlap = match compute_overlap(width, height, width, height, dx, dy) {
        Some(overlap) => overlap,
        None => return f32::MIN,
    };
    let x0 = region.x.max(overlap.prev_x);
    let y0 = region.y.max(overlap.prev_y);
    let x1 = (region.x + region.w).min(overlap.prev_x + overlap.width);
    let y1 = (region.y + region.h).min(overlap.prev_y + overlap.height);
    if x1 <= x0 || y1 <= y0 {
        return f32::MIN;
    }

    let mut prev_sum = 0.0f32;
    let mut curr_sum = 0.0f32;
    let mut count = 0usize;
    for prev_y in y0..y1 {
        for prev_x in x0..x1 {
            let curr_x = (prev_x as i32 - dx) as u32;
            let curr_y = (prev_y as i32 - dy) as u32;
            let prev_idx = (prev_y * width + prev_x) as usize;
            let curr_idx = (curr_y * width + curr_x) as usize;
            prev_sum += prev_gray[prev_idx];
            curr_sum += curr_gray[curr_idx];
            count += 1;
        }
    }
    if count == 0 {
        return f32::MIN;
    }

    let prev_mean = prev_sum / count as f32;
    let curr_mean = curr_sum / count as f32;
    let mut num = 0.0f32;
    let mut prev_var = 0.0f32;
    let mut curr_var = 0.0f32;
    for prev_y in y0..y1 {
        for prev_x in x0..x1 {
            let curr_x = (prev_x as i32 - dx) as u32;
            let curr_y = (prev_y as i32 - dy) as u32;
            let prev_idx = (prev_y * width + prev_x) as usize;
            let curr_idx = (curr_y * width + curr_x) as usize;
            let p = prev_gray[prev_idx] - prev_mean;
            let c = curr_gray[curr_idx] - curr_mean;
            num += p * c;
            prev_var += p * p;
            curr_var += c * c;
        }
    }

    if prev_var <= 1.0 || curr_var <= 1.0 {
        return f32::MIN;
    }
    num / (prev_var.sqrt() * curr_var.sqrt())
}
```

```rust
fn ncc_from_sums_matches_pearson_for_known_vectors() {
    let xs = [10.0f64, 20.0, 30.0, 40.0, 50.0];
    let ys = [12.0f64, 19.0, 33.0, 38.0, 52.0];
    let n = xs.len() as f64;

        n,
        sum_x: xs.iter().sum(),
        sum_x2: xs.iter().map(|v| v * v).sum(),
        sum_y: ys.iter().sum(),
        sum_y2: ys.iter().map(|v| v * v).sum(),
        sum_xy: xs.iter().zip(ys).map(|(a, b)| a * b).sum(),

    // Pearson r computed directly.
    let mx = sums.sum_x / n;
    let my = sums.sum_y / n;
    let mut num = 0.0;
    let mut vx = 0.0;
    let mut vy = 0.0;
    for (a, b) in xs.iter().zip(ys) {
        num += (a - mx) * (b - my);
        vx += (a - mx) * (a - mx);
        vy += (b - my) * (b - my);
```

```rust
fn clipped_ncc_rects(
    width: u32,
    height: u32,
    region: Region,
    dx: i32,
    dy: i32,
) -> Option<(Region, Region)> {
    let overlap = compute_overlap(width, height, width, height, dx, dy)?;
    let x0 = region.x.max(overlap.prev_x);
    let y0 = region.y.max(overlap.prev_y);
    let x1 = (region.x + region.w).min(overlap.prev_x + overlap.width);
    let y1 = (region.y + region.h).min(overlap.prev_y + overlap.height);
    if x1 <= x0 || y1 <= y0 {
        return None;
    }

    let prev_rect = Region {
        x: x0,
        y: y0,
        w: x1 - x0,
        h: y1 - y0,
    };
    let curr_rect = Region {
        x: (x0 as i32 - dx) as u32,
        y: (y0 as i32 - dy) as u32,
        w: prev_rect.w,
        h: prev_rect.h,
    };
    Some((prev_rect, curr_rect))
}

struct NccSums {
    n: f64,
    sum_x: f64,
    sum_x2: f64,
    sum_y: f64,
    sum_y2: f64,
    sum_xy: f64,
}

// One fused pass over the overlap rect. Because the cross term Sum(xy) must
// touch every pixel anyway, the four normalization sums are accumulated in the
// same loop for free. Eight columns per SIMD step via `chunks_exact(8)` (which
// makes the in-bounds slice provable, so no per-lane bounds check), with the
// `< 8` remainder handled in scalar f64. The SIMD lane sums are reduced into
// f64 **per row** (not once per region): raw second moments of a
// high-brightness row are large, so a region-wide f32 lane accumulator loses
// the low-order bits that `Sum(x^2) - Sum(x)^2/n` later cancels against,
// collapsing the variance signal on low-contrast windows. Folding to f64 each
// row bounds the lane magnitude to a single row.
fn fused_sums_wide(
    prev_gray: &[f32],
    curr_gray: &[f32],
    width: usize,
    prev_rect: Region,
    curr_rect: Region,
) -> NccSums {
    let (mut sum_x, mut sum_x2, mut sum_y, mut sum_y2, mut sum_xy) =
        (0.0f64, 0.0f64, 0.0f64, 0.0f64, 0.0f64);
    let row_width = prev_rect.w as usize;

    for row in 0..prev_rect.h as usize {
        let p0 = (prev_rect.y as usize + row) * width + prev_rect.x as usize;
        let c0 = (curr_rect.y as usize + row) * width + curr_rect.x as usize;
        let p_row = &prev_gray[p0..p0 + row_width];
        let c_row = &curr_gray[c0..c0 + row_width];

        let mut sx = f32x8::ZERO;
        let mut sx2 = f32x8::ZERO;
        let mut sy = f32x8::ZERO;
        let mut sy2 = f32x8::ZERO;
        let mut sxy = f32x8::ZERO;
        let mut pc = p_row.chunks_exact(8);
        let mut cc = c_row.chunks_exact(8);
        for (pa, ca) in pc.by_ref().zip(cc.by_ref()) {
            let p = f32x8::from(<[f32; 8]>::try_from(pa).unwrap());
            let c = f32x8::from(<[f32; 8]>::try_from(ca).unwrap());
            sx += p;
            sx2 += p * p;
            sy += c;
            sy2 += c * c;
            sxy += p * c;
        }
        sum_x += f64::from(sx.reduce_add());
        sum_x2 += f64::from(sx2.reduce_add());
        sum_y += f64::from(sy.reduce_add());
        sum_y2 += f64::from(sy2.reduce_add());
        sum_xy += f64::from(sxy.reduce_add());
        for (&p, &c) in pc.remainder().iter().zip(cc.remainder().iter()) {
            let (p, c) = (f64::from(p), f64::from(c));
            sum_x += p;
            sum_x2 += p * p;
            sum_y += c;
            sum_y2 += c * c;
            sum_xy += p * c;
        }
    }

    NccSums {
        n: f64::from(prev_rect.w) * f64::from(prev_rect.h),
        sum_x,
        sum_x2,
        sum_y,
        sum_y2,
        sum_xy,
    }
}

fn ncc_from_sums(s: NccSums) -> f32 {
    if s.n == 0.0 {
        return f32::MIN;
    }
    let numerator = s.sum_xy - (s.sum_x * s.sum_y / s.n);
    let var_x = s.sum_x2 - (s.sum_x * s.sum_x / s.n);
    let var_y = s.sum_y2 - (s.sum_y * s.sum_y / s.n);
    // Same reject floor as legacy `ncc_score_shifted`: var here is the
    // sum-of-squared-deviations (Sum(x^2) - Sum(x)^2/n), identical in scale.
    if var_x <= 1.0 || var_y <= 1.0 {
        return f32::MIN;
    }
    (numerator / (var_x * var_y).sqrt()) as f32
}
```

```rust
fn fast_ncc_score_shifted(
    prev: &PreparedFrame,
    curr: &PreparedFrame,
    region: Region,
    dx: i32,
    dy: i32,
) -> f32 {
    let (width, height) = prev.dimensions();
    let (prev_rect, curr_rect) = match clipped_ncc_rects(width, height, region, dx, dy) {
        Some(rects) => rects,
        None => return f32::MIN,
    };

    #[cfg(test)]
    with_active_search_budget(|budget| {
        budget.full_res_ncc_calls += 1;
        // Single fused pass visits each pixel once (legacy visited twice).
        budget.full_res_ncc_pixel_visits += u64::from(prev_rect.w) * u64::from(prev_rect.h);
    });

    let sums = fused_sums_wide(prev.gray(), curr.gray(), width as usize, prev_rect, curr_rect);
    ncc_from_sums(sums)
}
```

# Box Tools Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Track every checkbox and keep every task-ending commit green.

**Goal:** Deliver Slice 3 of the annotation-editor program: complete Rectangle and Ellipse creation, editing, styling, history, Navigator, live rendering, full-resolution output, remembered Shapes selector, and Linux/macOS Result Workspace verification.

**Architecture:** `rollshot-image-document` owns one committed `Annotation::Shape` family, validation, history, normalized image-space geometry, ellipse-aware hit testing, shared eight-handle anchors, Navigator semantics, render commands, and deterministic raster flattening. `rollshot-app` owns remembered Rectangle/Ellipse tools, independent persisted defaults, app-only drafts and style previews, four-screen-pixel gesture thresholds, Shift constraints, source-bound clamping, selector/menu state, and cursor feedback. Result Workspace and Timeline consume the same framework-neutral render commands; only Result Workspace gains creation and editing UX.

**Tech Stack:** Rust, `image`, serde/TOML, iced 0.14 built-in widgets and `Canvas`, existing snapshot history and atomic configuration persistence.

## Global Constraints

- Rectangle and Ellipse are `Annotation::Shape { kind: ShapeKind, bounds, stroke, fill }`; do not create parallel annotation lifecycles.
- Canonical Rectangle and Ellipse defaults are `#E5484D`, stroke width `4.0`, opacity `1.0`, fill disabled, remembered fill color `#E5484D`.
- Stroke is always present. Fill is `Option<Rgb8>`, solid, fully opaque, and has no opacity/style wrapper.
- Bounds are finite, normalized, positive, full-resolution image coordinates. Stroke is centered on the logical path and painted after fill.
- Creation supports every drag quadrant and commits only when both dimensions are at least four screen pixels at the current scale.
- Shift creation uses the smaller absolute drag-axis distance. Shift corner resize preserves the original aspect ratio; edge resize ignores Shift.
- Resize handles may cross the anchored side and continue after normalization while retaining at least four screen pixels on both axes.
- Outline-only interiors are selectable. Ellipse bounding-box corners outside the ellipse are misses. Handles precede bodies; topmost annotations win.
- Rectangle and Ellipse defaults and remembered `last_shape` persist independently. Selected-object edits never change defaults.
- Selected Shape property changes are one app-only preview transaction; Apply creates one history entry, Cancel creates none.
- Shapes is visible at Wide, Compact, and Narrow. Its primary action uses the remembered kind; only explicit selector choice changes and persists that kind. `S` activates it and never cycles.
- Copy and Save flatten committed state only. Drafts, style previews, selection, hover, and handles never enter output. Copy Original remains source-identical.
- Opaque Redaction remains the only secure redaction and retains fixed opaque-black rendering and OCR privacy-mask behavior.
- Use iced 0.14 built-ins, the existing anchored-menu composition, and the existing Canvas. Do not add Shader, a custom `Widget`, or custom `Overlay`.
- Do not add rotation, multi-selection, kind conversion, advanced styles, capture-overlay changes, Timeline creation, automation shape proposals, or stitching-core changes.
- Every shell command is prefixed with `rtk`. Do not create a worktree.

## Engineering Review Record (auto mode, 2026-07-14)

### Scope and reuse

- This is the minimum complete Slice 3: omitting document history, properties/defaults, gestures, discoverability, flattening, Navigator, or platform verification would leave an approved lifecycle incomplete.
- Reuse `StrokeStyle`, `ImageRect`, snapshot history, `PropertyState`, Canvas event routing, toolbar density/More routing, atomic TOML writes, inline errors, and native Copy/Save handoffs.
- Share only eight handle anchor geometry with Opaque Redaction. Do not merge its variant, renderer, style, secure-sharing classification, or validation.
- Add two focused modules and no crate, dependency, thread, async task, cache, service, or distribution artifact.
- Use fixed 4×4 coverage sampling in the new raster box functions. It is deterministic, local to the shape bounding box, easy to compare at the one-pixel edge tolerance, and does not disturb crisp redaction replacement.

### Data and test flow

```text
Rectangle/Ellipse persisted default ──press──> app-only raw draft
            │                                  │ scale / Shift / source bounds
            │                                  v
            │                           derived normalized preview
            │                                  │ release + 4 px/axis gate
            v                                  v
 remembered Shapes action             validated one-op batch
                                               │
                                  commit one Snapshot or no mutation
                                               │
                          Annotation::Shape { kind, bounds, stroke, fill }
                              │           │             │
                              │           │             └── Navigator
                              │           └── ellipse-aware hit / shared handles
                              └── RenderShape::Box ──┬── Result Workspace Canvas
                                                    ├── Timeline Canvas

                                      ├── Cancel: discard
                                      └── Apply: set_shape_style once
```

### Locked implementation decisions

1. Add `RenderShape::Box` carrying `ShapeKind`, logical bounds, opaque stroke color/width, and optional opaque fill. This keeps live and raster consumers on one command and avoids duplicate Rectangle/Ellipse variants.
2. Add `resize_handles` as the shared public helper and update the two in-workspace consumers in the same atomic task. Do not retain a second alias once all callers move.
3. Keep raster redaction on existing crisp `RenderShape::Rect`. New box fill/stroke functions use coverage blending and never change secure redaction pixels.
4. Represent selected-object edits with one `ShapeStyleTransaction` that owns original and preview stroke/fill plus the remembered in-transaction fill color. The color picker edits that preview; its local Apply closes the picker but does not mutate the document. Top-level Shape Apply performs the single document operation.
5. Keep default-tool edits immediate through the existing default persistence flow. Default changes are configuration only and do not open document history.
6. Retain the raw pointer in creation and resize drags. Modifier-only events recompute from raw input, so preview and release cannot disagree.
7. Keep split-control rendering as a `row![primary, chevron]` plus the existing expanded anchored-menu column. No custom overlay is needed.
8. Runtime completion requires native Linux and macOS Result Workspace checks. If either is unavailable, stop at `Handoff`; do not mark the registry `Complete` without a new explicit user waiver.

### Second-pass review decisions (auto mode, 2026-07-14)

9. Shift creation deliberately uses the smaller absolute drag-axis distance. Inspected references disagree (mark-shot uses the larger axis and binds square/circle to Ctrl, Flameshot averages both axes; only Spectacle binds Shift like this plan). The smaller axis keeps the square/circle inside both drag extents and is the approved spec behavior — do not "fix" it to match a reference.
10. True-ellipse body hit testing (bounding-box corner miss) intentionally diverges from mark-shot and Flameshot, which hit-test the axis-aligned bounding box. This is approved UX; keep it.
11. The ellipse stroke annulus (outer radii plus `width / 2`, inner radii minus `width / 2`) approximates a true centered offset stroke. Deviation grows with stroke width and eccentricity but stays within the approved one-pixel edge tolerance at product stroke widths; do not implement exact offset curves.
12. `box_tool::resized_bounds` intentionally coexists with the existing redaction `resized_rect` helper in `canvas.rs`. Do not modify or migrate the redaction resize path in this slice; unification is a possible follow-up, not Slice 3 scope.
13. Name every new test module and function so the exact `rtk cargo test` filter string written in each step matches it; never leave a step whose Run command selects zero tests.
